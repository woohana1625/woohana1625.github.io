Shorts-Upload 개인정보처리방침

시행일: 2026-11-04

Shorts-Upload(이하 「이 앱」)는 MoonHome 유튜브 채널(한국어·일본어 채널, 영어 채널 추가 예정)의 주인이 자기 컴퓨터에서 자기 채널에 숏폼 영상을 올리려고 쓰는 개인용 도구입니다. 채널 주인 본인만 쓰며, 다른 사람에게 제공하지 않습니다.

1. YouTube API 서비스 사용

  • 이 앱은 YouTube API 서비스(YouTube API Services)를 사용합니다.
  • 이 앱을 쓰면 YouTube 서비스 약관을 따르는 데 동의하는 것입니다: https://www.youtube.com/t/terms
  • YouTube API 서비스 약관: https://developers.google.com/youtube/terms/api-services-terms-of-service
  • Google 개인정보처리방침: https://policies.google.com/privacy

2. 접근하는 정보와 쓰임

  • Google 로그인 허락(OAuth 액세스·갱신 토큰) — 동영상 올리기(youtube.upload)와 내 채널 확인용 읽기(youtube.readonly)에만 씁니다. 채널 주인의 컴퓨터에만, 본인만 읽을 수 있게 저장합니다. 로그아웃하면 바로 지웁니다. Google 계정 화면에서 권한을 거둔 경우에는 그 토큰을 더 쓸 수 없게 되며, 저장된 토큰은 로그아웃하거나 삭제를 요청하시면 지웁니다.
  • 내 채널 ID·핸들 — 엉뚱한 채널에 올리지 않도록 대조하는 데만 씁니다. 채널 주인의 컴퓨터에만 저장하고, 올릴 때마다 YouTube 에서 다시 받아 갱신합니다. 29일 넘게 다시 받지 않은 채널 기록과 로그아웃한 채널 기록은 지웁니다(최대 30일 보관).
  • 올린 기록(파일 지문·채널·상태·날짜, YouTube 가 돌려준 영상 ID·공개 여부) — 같은 영상을 두 번 올리지 않고 결과를 확인하는 데 씁니다. 채널 주인의 컴퓨터에만 저장하고, YouTube 에서 받은 값은 받은 지 29일이 지나면 지웁니다(최대 30일 보관).
  • 올릴 영상과 제목·설명 — 채널 주인이 직접 만든 것이며, 채널 주인의 YouTube 채널에 올리는 데만 씁니다.

3. 밖으로 보내는 곳과 공유

  • 위 정보를 판매하거나 광고·분석에 쓰지 않습니다.
  • 이 앱이 밖으로 보내는 곳은 두 곳뿐입니다.
    • YouTube(Google) — 동영상 올리기와 내 채널 확인 요청.
    • 디스코드(Discord) — 채널 주인 본인만 보는 디스코드 작업 공간에 올리기 결과 한 줄(어느 채널인지 kr·jp·us, 성공·실패·중단과 그 까닭)을 알립니다. 이 알림에는 YouTube 에서 받은 값(영상 주소·영상 ID·채널 ID)을 넣지 않습니다. 디스코드에 보낸 글에는 디스코드의 개인정보처리방침이 적용됩니다.
  • 그 밖의 제3자에게는 넘기지 않습니다.
  • Shorts-Upload's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. (이 앱이 Google API 에서 받은 정보를 쓰고 넘기는 방식은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.)

4. 보호

  • 허락 토큰과 기록은 채널 주인의 컴퓨터 안 설정 폴더에 본인만 읽을 수 있게 둡니다. 토큰과 기록 자체는 서버나 다른 곳에 올리지 않습니다(디스코드 알림은 3절대로 YouTube 값 없이 결과 한 줄만 보냅니다).

5. 권한 철회와 삭제

  • Google 계정의 「서드 파티 연결」 화면에서 이 앱의 접근을 언제든 끊을 수 있습니다: https://myaccount.google.com/permissions
  • 이 앱의 로그아웃은 그 채널의 토큰을 Google 에서 끊고, 이 컴퓨터에 저장한 토큰과 그 채널 기록을 지웁니다.
